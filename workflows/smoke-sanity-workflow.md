# Smoke and Sanity Workflow

Smoke testing establishes that a new build and its environment are ready for deeper validation.

## Focus

Validate launch and navigation, core journeys, service health, key integrations, feature flags, and essential UI rendering after deployments, environment refreshes, and hotfixes. Blockers stop further testing until fixed and retested.
