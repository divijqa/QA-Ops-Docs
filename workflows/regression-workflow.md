# Regression Workflow

Regression testing confirms that changes do not break established product behavior.

## Workflow

Define a risk-based scope, prepare the suite and environment, run smoke, functional, exploratory, and applicable automated regression, triage findings, verify fixes, report coverage and risk, then update the suite with learning from the cycle.
