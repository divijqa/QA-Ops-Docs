# QA Reporting Standards

Consistent reports turn testing activity into timely, actionable release signals.

## Required reporting

Use daily status, smoke results, regression summaries, final sign-off, and hotfix reports. Each report identifies release context, execution and defect metrics, environment status, risks, blockers, next steps, owner, and recommendation.
