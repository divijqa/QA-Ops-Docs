# Environment Checklist

- [ ] Deployment, configuration, flags, services, APIs, and application health are verified.
- [ ] Test data, accounts, roles, and access are ready.
- [ ] Internal and external integrations respond as expected.
- [ ] Monitoring and logs are available with no active critical alerts.
- [ ] QA has validated the environment and any issue is tracked to resolution.

[View the canonical wiki page](https://github.com/divijqa/QA-Ops-Docs/wiki/Environment-Checklist)
