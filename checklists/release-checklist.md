# Release Checklist

- [ ] Scope, requirements, build, environment, flags, and test data are ready.
- [ ] Functional, regression, smoke, exploratory, and applicable automation testing are complete.
- [ ] Critical defects are resolved; high defects are resolved or accepted.
- [ ] Risks, artifacts, deployment, rollback, and monitoring plans are reviewed.
- [ ] Go/no-go approvals and production validation are complete.
