# Regression Checklist

- [ ] Build, environment, data, scope, and ownership are ready.
- [ ] Smoke, functional, exploratory, and automated regression have been executed.
- [ ] Defects are logged, triaged, verified, and blockers escalated.
- [ ] Coverage, risk, reports, and the release recommendation are complete.
